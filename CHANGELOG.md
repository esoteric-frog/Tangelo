# Changelog

## 0.1.0

- Menu-bar app: drop files on the icon, pick a format.
- Convert wheel (hold ⌃ while dragging): JPG, PNG, TIFF, HEIC, AVIF, WebP, Smaller PDF.
- Tools wheel (⌘): Compress, Resize 50%, Smaller PDF.
- Actions wheel (⌥): AirDrop, Copy Files, Copy Paths, Open in Terminal, Show in Finder.
